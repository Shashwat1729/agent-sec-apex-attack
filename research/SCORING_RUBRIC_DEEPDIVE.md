## 1. Per-criterion: what reviewers look for, common failures, what 1st-place notes do differently

Conventions below: each criterion lists **Looks for** (reviewer checklist), **Common failures** (what kills PASS), and **What 1st-place notes do** (3-4 of the 50 with the specific technique to copy). Set-A refs = research/WINNING_NOTES_A_25.md, Set-B = research/WINNING_NOTES_B_25.md.

### C1 — Technical clarity and reproducibility

**Reviewers look for:** Can I re-run the headline in 5 minutes from the skim-path (TL;DR + Fig 1 + one table + code links), then audit everything in 30 minutes? Concretely: 4-6-sentence TL;DR with what/why/score/repo (`guide:22-36`); pipeline figure FIRST (`guide:66`); every claim as `idea -> fence (10-25 lines, runnable, # Expected:) -> isolated delta +x.xx` (`guide:76,129`); exact hyperparams/seeds/hardware/commands/versions; no prose-only claim (`guide:129`).

**Common failures:** (a) Listing 20 actions without isolated deltas (`guide:111` — "20 subs without isolated delta"); (b) 74-row inline dumps instead of 4-8-row narrative tables + chunked appendices (`guide:50`); (c) Plots without captions/interpretations (`guide:72,128` pitfall #5); (d) Missing baseline/minimal control so the delta has no anchor; (e) Reproducibility as weakest norm overall (Set-A cross-cutting #5) — seeds/hardware/requirements omitted because "code linked" feels sufficient. It is not.

**What 1st-place notes do differently (copy these):**
- **LEAP-ClimSim 1st greysnow, "no-leaky" (A#13): integrity front-loading.** Leak-inoculation section FIRST — full Kaggle pipeline HF->TFRecords->train->infer, 100+ copy-run notebooks reproducing ~0.79+, then architecture (Squeezeformer + wide-GLU head, MAE, confidence head). Every "secret sauce" ablated away while still winning (no-spacetime 6-model 0.79355/0.79092 "I win anyway"). Technique to copy: provenance block (data hashes, pipeline links, no-leak ablation) BEFORE method, ideally flagged in the title.
- **IEEE-Fraud 1st Deotte/Yakovlev (A#1): reframe + per-trick LB ladder.** Opens with the domain reframe ("labels are per-credit-card, not per-transaction"), then UID 2-liner (`card1+addr1+D1`), GroupKFold-by-month, and a before/after number on EVERY trick (XGB 0.9510 -> +UID aggs 0.9602 -> +postprocess 0.9618; public 0.9677/private 0.9459). Technique to copy: attach a paired CV/LB delta to every claim; the table replaces adjectives.
- **Santa-2025 1st jeroencottaar (A#25): notebook-first + gallery proof.** "Read the notebook first" inverted pedagogy + 2 runnable notebooks + full 200-solution gallery figure legible in 10 seconds. ### C2 — Methodological contribution

**Reviewers look for:** One transferable method (not just "we won"), stated as a rule + the ablation that proves the rule. Validation methodology itself counts as the deliverable (Numina A#18 pattern). Ideal shape: unified harness (same folds/seed/metric for all variants) -> comparison table -> selection/blend rule -> seed-variance proof that the rule is stable.

**Common failures:** (a) Blending on vibes — weights without a unified-CV harness table (House-Prices A#4 anti-pattern); (b) Single-seed headline numbers (Jigsaw A#12 / MAP A#16 warning — same config, medal-or-not swings); (c) No ship/no-ship rule, or a rule stated then silently violated (ISIC A#10 violation is forgiven ONLY because it is logged); (d) Novelty claimed on architecture when the edge is validation/inference engineering (MAP A#16 systems-hacker lesson).

**What 1st-place notes do differently:**
- **Optiver-Close 1st hyd (A#6): one 5x5 ablation table as centerpiece.** 5 models x 5 treatments — validation w/o-w/PP, test w/o-OL, OLx1, OLx5 (CatBoost 5.8287 -> 5.4165; final blend 5.8117/5.4030, overtime). Zero figures — the table carries the note. Technique to copy: models-x-treatments matrix with paired numbers; each cell answers "does this component survive without the others?"
- **MAP-2025 1st (A#16): seed-variance table + trust-LOSS rule.** 8-model comparison with single-seed loss/MAP@3 triplets + 3-seed ensemble columns (Qwen3-32B 0.2589/0.9484 -> +GLM-Z1 ensemble 0.2530/0.9496); "trust LOSS over MAP@3"; multi-seed >> multi-fold; auxiliary-SFT kept as marginal (negative-ish result not hidden). Technique to copy: never report a single-seed headline — show the triplet + ensemble column + which metric to trust.
- **ARC-2024 1st ARChitects (B#5): selection rule as the contribution.** Test-time-training on NeMo-Minitron-8B + novel augmentations + stability-based selection (pick the stable-across-augmentations candidate, not the likely one), induction+transduction ensemble framing, Apache-2.0 + retrain recipe + wheels + weights + params.json. Technique to copy: publish the rule that PICKS among candidates with the ablation that proves the rule (stability vs likelihood).
- **Vesuvius-Ink 1st ryches (B#9): invariance + breaking control.** Depth-invariance as explicit design constraint (3D UNETR -> 32ch -> SegFormer-b5), crop ladder 128 < 512 < 1024 at IDENTICAL wall-clock ("context is free"), channel-shuffle failed-convergence ablation in thread. Technique to copy: state the invariance the architecture guarantees, then show the control that breaks without it.

### C3 — Security insight

**Reviewers look for:** Threat model stated up front; attacker capability per lever named; the hole made FALSIFIABLE in <60 s (runnable probe, not prose); temporal/artifact negative controls run BEFORE model-gain claims; public-vs-private (or train-vs-test) per-component deltas where the board can shift. In security-adjacent work the negative control is often more cited than the win (Malware-2019 7-liner).

**Common failures:** (a) Claiming model gains before running the trivial version/date-segment control; (b) Collapsing vote/uncertainty to hard labels silently (HMS B#11 warning); (c) Reporting public LB as final when the metric is gameable (Home-Credit A#5, ASHRAE B#16 warnings); (d) Describing the guardrail in prose + config dump with no copy-paste falsification loop.

**What 1st-place notes do differently:**
- **Malware-Prediction-2019 7-liner (A#21): the perfect negative control.** 7-line pandas AvSigVersion exploit (all-zero predictions, 0.681 private = 1st) proving the private board measured sampling lag, not skill; taper refinement 0.696 + detection-lag explanation. Technique to copy: always run and report the trivial temporal-artifact control (version/date segments) before any model claim.
- **LANL-Earthquake 1st Zoo (B#19): "completely ignore public LB."** Train-test alignment via paper-p4677 statistics, 150+ acoustic features, KS-test train-vs-test plots, alignment on/off +0.27 (2.58 -> 2.31 independently reproduced in thread), LGBM-only 2.279 + NN geomean 2.25993, adversarial comment scrutiny survived. Technique to copy: when boards shake, show the distribution plot + alignment ablation; distrust is a result with numbers.
- **Home-Credit-2024 1st yuuniee (A#5): betting disclosure.** Separated Phase-1 ML (StratifiedGroupKFold, LGBM/CatBoost/Denselight) from Phase-2 metric hack (WEEK_NUM reversal, DEVIDE/REDUCE grid, public optimum 0.03 / private guess 0.02-0.04), two-submission hedge, credited leak reporters by name and proposed Kaggle award them. Technique to copy: separate skill from luck/betting, quantify the luck, credit finders.
- **RSNA-Aneurysm-2025 1st (B#2): cascading gate metrics.** Coarse-to-fine pipeline where stage 1 (vessel segmentation) is evaluated as a recall gate for stage 2 (ROI classifier); ROI-vs-whole-volume gate ablation; multimodal CTA/MRA handling. Technique to copy: for detection-then-decide pipelines report per-stage metrics + the gate-ablation (no-ROI vs ROI), not one headline number.

### C4 — Usefulness to benchmark community

**Reviewers look for:** Can the next team copy-paste this and save GPU-hours? Reusable artifacts: feature/artifact registry tables, numbered notebooks in run order with BASE_PATH + artifact URLs + OOM workarounds, cost axis next to score axis (params/latency/wall-clock), keep/never-retry tags on failures, per-structure/per-head ablations for structured label spaces.

**Common failures:** (a) "We did FE" without a registry (Rossmann A#2 anti-pattern); (b) Final ensemble only, no small-model config / efficiency Pareto (Hydrogen B#8 warning); (c) No tool-assignment justification in hybrid ML+LLM work — which subtask each tool wins and which failures forced the split (MDC B#25 warning); (d) Full-field claims with only top-20 shown and no pointer to the exhaust path (DIAGNOSIS RC6 warning).

**What 1st-place notes do differently:**
- **Rossmann 1st Gert (A#2): feature dictionary as the artifact.** 60+ features x 4 membership flags (salesmodel/customermodel/MA/pmd-variant) + prev* naming convention (ds/dps/dphs x med/m1/m2/m3/m4/hmean) + 12-model ensemble list + holdout-mirrors-time-split rule. Technique to copy: ship the full registry (name/definition/membership/rationale), not a summary.
- **CommonLit-2021 1st mathislucka (B#20): runnable factory.** 5 ordered Colab notebooks (prep/external/label/train/infer) + Kaggle pseudo-label kernel + 10 weight packs + BASE_PATH convention + CUDA-OOM restart note + ridge-ensemble over folds + dropout train-vs-eval pathology. Technique to copy: number pipeline notebooks in run order with pinned artifact URLs; document the memory failure mode and workaround.
- **Feedback-Efficiency 1st Hydrogen (B#8): dual-track reporting.** TWO solutions from one codebase (accuracy + efficiency tracks), two-level stacking (DeBERTa-family + second-stage), efficiency yaml + inference kernels, efficiency-vs-accuracy Pareto table. Technique to copy: report score AND cost; ship the small-model config, not just the winning ensemble.
- **MDC-2025 1st Ali/Kohv (B#25): tool-assignment matrix + 4 named failures.** Split by mention TYPE first (DOI: Data-Citation-Corpus + 6xCatBoost on title/author/year-similarity; acc-ids: EUPMC + zero-shot Qwen context-snippet; BioSample exception), stage-addition ladder (doi-only 0.362/0.350 -> +acc 0.754/0.664 -> +Qwen 0.890/0.797), what-did-not-work with reasons (Qwen-for-DOI worse, DataCite-relations, fancy prompts, Marker-OCR too slow). Technique to copy: matrix of which tool wins which subtask + failures that justify the split.

### C5 — Responsible communication

**Reviewers look for:** Honesty under pressure: variance disclosed (never single-seed), decision rule + every override logged with outcome, small-n selection protocol confessed, misses credited to rivals by name, stop rule stated, luck/betting/probing disclosed, labels CLAIM vs VERBATIM vs INFERRED where exactness varies. Responsible is a VETO criterion — a strong-methods note with hidden probing or uncredited borrowing fails outright.

**Common failures:** (a) Selecting on a 120-sample public board without saying so (Lonnie B#6 heresy — 344th-public -> 5th-private on seed 19920627); (b) Lowering the ship threshold under pressure and hiding it (ISIC A#10 forgiven ONLY because logged); (c) Title-embedded self-claims cited as verified scores (DIAGNOSIS RC3 — 95.130/66.015/60.525 are CLAIM, not VERBATIM); (d) No "what we missed / others did better" section — reads as victory lap (MCTS A#23 warning); (e) Control-token / injection techniques documented without a prominent safety banner + defense pointer (`guide` pitfall #8).

**What 1st-place notes do differently:**
- **ISIC-2024 1st Novoselskiy (A#10): ship-rule + violation log.** 5-fold StratifiedGroupKFold x10 seeds, t-test p<0.05 ship rule, then honest account of violating it (lowered to 0.2, leaned on public LB after sliding 23rd-down; final better public, slightly worse private). Per-trick CV+public+private deltas (LOF 0.18149->0.18185). Technique to copy: state the statistical rule AND log every override with its outcome.
- **MCTS-variants 1st James Day (A#23): Trust-CV-vs-Trust-LB + missed avenues.** Per-trick CV/LB delta ledger (every section ends with paired numbers), dedicated strategy section ("Trust CV beat Trust LB on BOTH boards"), failures + "flip augmentation — 0.01 better hybrid exists?!" crediting goldenlock, dependency pin with VERSION discrepancy disclosed. Technique to copy: close with failures + missed avenues + credit, with numbers.
- **Titanic honest-reporting (A#3): negative tuning with stop rule.** Step table CatBoost+815-FE 0.824 CV -> 0.81578 LB vs Optuna-tuned 0.847 CV -> 0.794 LB (CV-up-2.3% / LB-down-2.2%), strict-vs-loose reproduction anecdote (7% CV gap from scaler/encoder fit details), "know when to stop." Technique to copy: publish one failed experiment with exact deltas + the stop rule.
- **Porto-Seguro 1st Jahrer (B#15) + ASHRAE 1st Isamu/Matt (B#16): noise + shakeup honesty.** Jahrer: denoising-autoencoder pretraining on 600Kx59 anonymized rows, CV-noise std ~0.01+ reported prominently on a 0.65-AUC-ceiling task, 463-comment lab notebook. ## 2. Scoring mental model: likely weights, gates, and what makes a note WIN vs just PASS

> Caveat: the host rubric lists 5 criteria without numeric weights and states leaderboard is supporting evidence only (`docs/WORKING_NOTE_V6.md:20-22,53,73`). The model below is INFERRED from 50 notes + `writeup_style_guide.md` — treat as a planning prior, not a quote.

### 2.1 Likely weighting (planning prior for V7 effort allocation)

| Criterion | Inferred weight | Why (evidence) |
|---|---|---|
| C1 Technical clarity + reproducibility | ~30% (gate) | Reviewer skim-penalty is the #1 enemy (`V6_REBUILD_PLAN.md:6`): >6k words loses reviewers (`guide:38`), >10-row tables moved out (`guide:50`), >8 figures = bloat (`guide:72`). Terse winners ship 0-2 figures and still win (LMSYS A#14: 700 words, 0 figures; Optiver A#6: 1200 words, 0 figures) — density beats length (median 1500-2500 Set-B / 1800-2500 Set-A). If the skim-path fails, other criteria are never read. |
| C2 Methodological contribution | ~25% | The only criterion with afterlife: validation tricks cited 3 years later (Feedback-2022 3-seed ensemble -> MAP-2025, A#19). One ablation table + one selection rule outranks five tricks without numbers. |
| C3 Security insight | ~20% (domain multiplier) | In a security competition this is the differentiator that converts a throughput report into a security note. Negative controls (A#21 7-liner), alignment plots (B#19), gate ablations (B#2) are the highest citations-per-word artifacts. |
| C4 Usefulness | ~15% | Factory > story (CommonLit B#20 chain, ARC B#5 wheels+weights, TalkingData B#14 registry). Judged by "would this save me GPU-hours next competition?" — registries, run-order notebooks, cost axes, keep/never-retry tags. |
| C5 Responsible communication | ~10% + VETO | Smallest share when clean, largest penalty when violated. Hidden LB-probing, uncredited borrowing, or CLAIM-as-VERBATIM flips a win to a fail. Honest violation logs (ISIC A#10) and betting disclosures (A#5) are instead rewarded — candor is award fuel. |

Gate logic, not additive logic: C1 is a hard gate (unreadable = unscored); C5 is a veto (dishonest = failed); C2+C3 decide rank among readable-honest notes; C4 breaks ties. Leaderboard position buys credibility but never compensates for a missing ablation, missing variance, or missing failures section (cf. APTOS Zoo 9th A#9 out-cited many 1sts on pseudo-labeling evidence; Titanic A#3 has no rank at all and is canonical on honest reporting).

| Level | What it looks like | V6 analogue |

**One-line mental model for V7:** Reviewers score `skim-path (TL;DR + Fig 1/2 + Table 7-A + Sec 8 + variance box) x honesty multiplier (CLAIM/VERBATIM/INFERRED + override log + credit) + exhaust-path bonus (chunked 74 + banded 630 + Fig 11 + matrix, all honestly labeled)`.
